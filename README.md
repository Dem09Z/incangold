# incangold
Respository for remake incangold boardgame and use it in discord bot for easy online play

how to use you need to have your discord bot token first then create token.env file same folder as app.py

and put your discord bot token there with this format : DISCORD_TOKEN=XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX (replace x with token)

you good to go now 

when run app.py discord bot will be online and you can start check command and use it to play :D
